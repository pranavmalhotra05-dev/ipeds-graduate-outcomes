# tableau_ready data dictionary

Generated by `src/02_build_measures.py` on 2026-11-20 11:15. Flat CSVs, UTF-8, snake_case, empty cell = null. All files cover IPEDS file years 2020-2023 (completions final/revised `_RV` release; enrollment fall 2020-2023, fall 2023 provisional). 2024 completions are PROVISIONAL and are not used.

Base: completions with MAJORNUM = 1 (first majors), CIPCODE <> 99 (no total rows), AWLEVEL 7, 17, 18, 19. A program cell = institution x CIP6 x award level x year. Counts are degrees/awards, not students.

Suppression: primary threshold 10 (count < 10 hidden, zero counts included) plus two complementary passes (see `measure_definitions.md`). No program-level count below 10 appears in any file here; the unsuppressed program file is written to a git-ignored local file under `outputs/` and must not be published.

Ratios named `ratio_*` are completions divided by graduate enrollment. They are NOT cohort completion or graduation rates.
Percent columns (`yoy_pct_change`, `pct_change_vs_2020`) are in percent units (4.2 = +4.2%).
