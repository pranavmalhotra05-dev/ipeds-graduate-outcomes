## Problems and caveats

- C2024_A is provisional only; EF2024A is not published (404). Latest year with data for all three surveys is 2023 (completions final/revised, enrollment provisional). HD2024 exists and is loaded.
- Completions CIPCODE values are only 6-digit codes (dd.dddd) plus '99' (grand total); no 2-digit or 4-digit rollup rows exist in the data, so family-level figures must be aggregated by the first 2 characters of cipcode.
- AWLEVEL and MAJORNUM are zero padded in the 2020 file (e.g. '05', '07'); they are cast to integers on load. The master's-total comparison above uses the numeric cast (a string comparison would give 0 for padded years).
- EF2023A (fall 2023) is labelled 'Provisional release' in its dictionary and no _RV file exists, so the enrollment table's latest year is provisional.
- No hand edits to raw downloads; all parsing is in this script.
